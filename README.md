# MASKA MARKET — Telegram-бот

Шаблон Telegram-магазина с навигацией через inline-кнопки: переходы редактируют одно сообщение, отдельные сообщения меню не создаются. Баннер не включён — изображение можно добавить позже.

## Возможности

- Главное меню и переходы: Купить товар, Мои покупки, Баланс, Акции, Наши ссылки, Поддержка, Информация.
- Каталог и карточки товаров из `products.json`.
- Поддержка: пересылка сообщения в `ADMIN_CHAT_ID`, если он настроен.
- Цветные кнопки Telegram: зелёные для покупки/каталога, красные для акций и возврата в главное меню, синие для остальных разделов. Цветовые стили доступны в поддерживаемых версиях клиентов Telegram; произвольный фиолетовый цвет через Bot API задать нельзя.
- GitHub Actions для сборки Windows EXE.

## Важно

Это стартовый шаблон. Реальные платежи, подтверждение банковских переводов, USDT-проверка TXID, база заказов, баланс и автоматическая выдача цифровых товаров **не реализованы**. Кнопки честно сообщают об этом; не принимайте оплату через бота до подключения и проверки платёжной логики.

## Запуск локально в Windows / VS Code

1. Установите Python 3.11.
2. Откройте папку проекта в VS Code и в терминале выполните:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   Copy-Item .env.example .env
   ```

3. Создайте бота через `@BotFather`, скопируйте токен и вставьте его в `.env` вместо `PASTE_YOUR_BOT_TOKEN_HERE`.
4. При необходимости укажите `SUPPORT_USERNAME` и `ADMIN_CHAT_ID`.
5. Запустите:

   ```powershell
   python main.py
   ```

## Как настроить товары

Отредактируйте `products.json`. Каждый товар должен иметь уникальные `id`, `name`, `description` и `price`. Для JSON используйте двойные кавычки и не ставьте запятую после последнего элемента.

## Сборка EXE через GitHub

1. Создайте пустой репозиторий GitHub и загрузите в него содержимое папки проекта, кроме `.env`.
2. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
3. Запустите workflow **Build Windows EXE** через **Run workflow** либо отправьте коммит в `main`/`master`.
4. После завершения откройте запуск workflow и скачайте артефакт `MaskaMarketBot-Windows`.
5. EXE не содержит токен. Рядом с EXE создайте файл `.env` с `BOT_TOKEN=...`; файл `products.json` также должен лежать рядом, чтобы изменения каталога применялись без пересборки. Для сборки шаблон копирует `products.json` внутрь EXE, но внешний файл не обязателен.

**Безопасность:** не загружайте `.env` в GitHub и не публикуйте токен. Если токен попал в репозиторий или чат, отзовите его через `@BotFather` и создайте новый.
